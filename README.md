# Supermarket Sales Dashboard (Excel)

## Project Overview

This project is an interactive Excel dashboard built using a supermarket sales dataset.

The objective is to analyze sales performance, product performance, customer purchasing behavior, city-wise revenue, and payment preferences using Excel's analytical and visualization features.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards
* Data Visualization

## Dashboard Features

### KPI Metrics

* Total Revenue
* Total Transactions
* Quantity Sold
* Average Order Value

### Analysis Performed

* Monthly Revenue Trend
* Revenue by Category
* Revenue by Product
* Revenue by Payment Method
* Revenue by City

### Interactive Filters

* Payment Method
* City
* Category
* Product Name

## Key Insights

* Top Category: Beverages
* Top City: Chennai
* Top Product: Coffee
* Preferred Payment Method: Card
